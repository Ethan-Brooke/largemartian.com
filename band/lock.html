Update the band room

The band room's contents are stored encrypted. This page unlocks them in your browser, lets you edit, and gives you a new encrypted file to upload. Nothing you type here leaves your computer.

1. Unlock

2. Edit

Plain JSON. The usual edits:

  1. Calendar: set "calendar" to the Google Calendar embed URL (Calendar settings → Integrate calendar → copy the src="…" part of the embed code) and "calendarLink" to its share link.
  2. New session: add { "date": "YYYY-MM-DD", "title": "Practice", "url": "…drive folder link…" } to "archive". Add "kind": "show" for a gig.
  3. Set list: add { "title": "…", "note": "…", "songs": ["…", "…"] } to "setlists".

3. Lock and download

Then upload it: go to the band folder on GitHub → Add file → Upload files → drop in band.enc.json (it replaces the old one) → Commit. Live in about a minute. If you changed the password, tell the band.
